# davidalindahl.com (v4)

Personal site of David A. Lindahl: a single page with a retro green-phosphor look and an
interactive ASCII computer in the hero.

**Stack:** [Astro](https://astro.build) 7 · [Vue](https://vuejs.org) 3 components ·
[Tailwind CSS](https://tailwindcss.com) 4 · Cloudflare Workers.

- **Content** lives in JSON (`content/site.json`, `content/experience.json`), validated
  against JSON Schemas in `content/schema/` on every build. Editors with JSON Schema
  support get autocomplete and inline errors via the `$schema` key.
- **Components** are Vue SFCs. Astro renders them to static HTML, and only the islands
  (the ASCII computer and the clock) ship JavaScript.
- **Design tokens** live in Tailwind's `@theme` (`src/styles/global.css`). Tailwind's
  default palette and type scale are switched off, so only the site's tokens exist as
  utilities.
- **Hero**: a 3D model drawn in text. Each character cell is raymarched against a signed
  distance field, shaded, and mapped to ASCII, in a Web Worker on an OffscreenCanvas so
  the page stays responsive. The pointer tilts the machine and drags a lens that
  magnifies, ripples and glitches the characters. Click, tap or press Enter to change
  the words on its screen.
- **Security**: a hash-based Content Security Policy generated by Astro, plus headers in
  `public/_headers`.
- **Agent-friendly**: see [`AGENTS.md`](./AGENTS.md) for the repo map, component and
  styling rules, and what must never be committed.

## Develop

Requires Node 22.23.4 or newer (`.nvmrc`).

```bash
npm ci
npm run dev
```

`npm run dev` serves http://localhost:4321 with hot reload.

```bash
npm run preview
```

`npm run preview` builds for production and serves the result with `wrangler dev`, which
applies `public/_headers` and the CSP like Cloudflare does.

```bash
npm test
```

## Deploy

Continuous deployment to Cloudflare Workers runs from GitHub Actions
(`.github/workflows/deploy.yml`):

- **Push to `main`:** production deploy.
- **Push to any other branch:** a Worker Preview with its own URL, linked from the run and
  the PR.
- **Branch deleted:** its preview is deleted.

One-time setup (Cloudflare API token, account ID and GitHub settings) is in
[`docs/deployment.md`](./docs/deployment.md). To deploy by hand:

```bash
npm run deploy
```

## Fonts

The design uses **MD Thermochrome** (Mass-Driver), a commercial typeface that is not
committed to this public repo. Until it's added, the site uses self-hosted IBM Plex Mono
(OFL). See [`src/fonts/README.md`](./src/fonts/README.md).
